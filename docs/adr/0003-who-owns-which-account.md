# Developer owns code and hosting; the business owns its domain and photos

The site's code lives in a private repo under the developer's GitHub account (EthanBautista), and Netlify hosting is on the developer's account, because the developer maintains both and Netlify connects most simply to a repo its own account can reach. The business (likhaproductions25@gmail.com) owns the Cloudinary account holding its photos and the `likhaevents.ca` domain registration, so it keeps its work and its address even if the developer steps away. The owner gets a GitHub account added as a collaborator on the repo, which is how they log in to the editor page.

## Consequences

Handing the site over means transferring the repo and re-linking Netlify. Inquiries pass through the developer's Netlify account as well as reaching the owner's inbox.
